Dark Studio

Dark Studio is a private, self-hosted tool used by its owner to manage their own YouTube channels: planning videos, tracking performance and reviewing channel analytics in one place.

How it uses Google data

With the owner's explicit consent, Dark Studio connects to the YouTube Data API and the YouTube Analytics API to read channel information, video lists and analytics reports for the channels they own. The app runs locally on the owner's computer and is not offered as a public service.
